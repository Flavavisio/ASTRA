# ASTRA v1.9 — Licenças Super Admin

Supabase criado:
- tabela `license_events` com RLS;
- histórico de ativações/renovações/remoções;
- RPC `admin_set_premium`;
- validação do Super Admin executada no servidor;
- licenças: 1/3/6/12 meses, vitalícia, suspensão/revogação;
- origem `super_admin`, nota, autor e timestamps.

Frontend:
- módulo `admin-licenses.js`;
- área Gestão de Licenças no Super Admin.

Segurança:
A RPC administrativa foi criada como SECURITY DEFINER mas valida `auth.uid()` contra Super Admin antes de alterar qualquer licença.
A tentativa de converter o UPDATE geral de `profiles` para grants apenas por colunas foi bloqueada pela camada de segurança da ferramenta e NÃO foi aplicada. Esse hardening continua obrigatório antes de produção.
