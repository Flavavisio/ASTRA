# ASTRA v2.7 — Conta ASTRA

Fluxo alterado conforme definido:

## Login
Na área Conta ASTRA aparecem apenas:
- Email
- Password
- botão Entrar
- link Criar conta

O login é único para utilizadores e Super Admin. O encaminhamento por permissão continua invisível.

## Criar conta
Ao clicar em Criar conta abre um modal com:
- Nome completo
- Email
- Password
- Confirmar password

Valida nome + apelido, email, mínimo de 6 caracteres e confirmação da password.
A conta é criada no Supabase Auth e o nome completo segue nos metadados para o trigger de criação do perfil.
