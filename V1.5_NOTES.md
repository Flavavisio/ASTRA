# ASTRA v1.5 — cálculo natal real

Implementado:
- Swiss Ephemeris WebAssembly carregado no browser por módulo ES;
- hora local -> UTC com timezone histórico IANA;
- Julian Day;
- posição real da Lua;
- casas Placidus;
- Ascendente e Descendente;
- gravação dos signos calculados no Supabase;
- estados de loading/erro e botão de recalcular.

A integração usa uma versão CDN fixa (`v0.1.0`), nunca `main`, para evitar builds inesperados.

## Antes de produção
- validar uma bateria de mapas contra uma referência independente;
- aumentar a base de localidades/geocoding;
- idealmente empacotar a dependência com um bundler em vez de depender do CDN;
- confirmar licenciamento aplicável do Swiss Ephemeris para distribuição comercial.
