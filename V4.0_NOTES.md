# ASTRA v4.0 — Interface da referência
A aplicação autenticada foi reconstruída visualmente para seguir a última imagem aprovada:
- sidebar no PC com Início, Horóscopo Diário, Mapa Astral, Compatibilidade, Trânsitos, Artigos, Conta e Premium;
- hero cósmico com saudação, data, planetas e signos;
- indicação “Consulta gratuita — 1 por dia”;
- símbolo zodiacal destacado junto ao signo;
- cards Amor / Trabalho / Saúde & bem-estar em 3 colunas no PC;
- layout mobile adaptado para uma coluna e navegação inferior;
- identidade ASTRA dourado/roxo;
- funcionalidades/IDs existentes preservados para não desligar Supabase, consulta, perfil e Premium.

Algumas novas entradas laterais reutilizam vistas existentes enquanto os respetivos módulos completos ainda não existem.
