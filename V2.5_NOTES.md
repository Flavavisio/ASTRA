# ASTRA v2.5 — Login único e Admin discreto

- Removidas do `index.html` referências públicas ao Super Admin / painel administrativo.
- Todos usam exatamente o mesmo login.
- Após autenticação, o sistema consulta `profiles.is_super_admin`.
- Utilizador normal → `app.html`.
- Super Admin → `admin.html`.
- `admin.html` já não apresenta formulário próprio de login.
- Sessão anónima em `admin.html` → redireciona para `index.html`.
- Utilizador autenticado sem permissão → redireciona para `app.html`.
- Adicionado `noindex,nofollow,noarchive` ao painel administrativo como medida adicional de discrição.
- A segurança continua dependente da autorização/RLS/RPC no Supabase, não do facto de a página estar escondida.
