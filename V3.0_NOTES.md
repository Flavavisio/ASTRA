# ASTRA v3.0 — Correção modal Criar Conta

Corrigido o X de fechar o modal de criação de conta.

Causa:
`auth.js` era carregado antes do `<dialog id="signupDialog">`. Assim, quando o JavaScript tentava associar o evento ao botão `closeSignup`, esse botão ainda não existia no DOM.

Correção:
- scripts do index movidos para o fim do `body`;
- inicialização de `auth.js` protegida por `DOMContentLoaded`;
- o X fecha agora o modal;
- mantido o fluxo Login / Criar conta e todas as alterações anteriores.
